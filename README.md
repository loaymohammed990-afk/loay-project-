# Loay Portfolio V1.0

موقع لؤي محمد الظاهري: React 19 + TypeScript strict + Vite، بالعربية والإنجليزية، RTL/LTR، وثيم داكن افتراضي وفاتح. تطبيق ثابت دون خادم أو قاعدة بيانات.

## التشغيل

المتطلبات: Node.js 22.12+ أو 24 LTS وnpm. جرى التنفيذ باستخدام Node 24.19.0 وnpm 11.17.0 على Windows.

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

التطوير عادة على `http://localhost:5173`، ومعاينة الإنتاج على `http://localhost:4173`. ملفات النشر داخل `dist/`. افتح عبر خادم HTTP، وليس بالنقر على index.html من مستكشف الملفات.

## تعديل المحتوى

- `src/data/portfolio.json`: الهوية والتواصل والمهارات والخدمات والمشاريع. النصوص المترجمة كائنات `{ "ar": "...", "en": "..." }`.
- `src/data/i18n.json`: نصوص الواجهة، تسميات الوصول ورسائل النموذج في اللغتين. احتفظ بالمفاتيح متطابقة.
- `src/types/index.ts`: أنواع البيانات؛ تصنيف المشروع `project` أو `training`، والمعرّفات ثابتة وفريدة.
- `src/styles.css`: الألوان والثيمين والتخطيطات المتجاوبة والحركة. خط Cairo موحد للعربية والإنجليزية، وDM Mono للكود الزخرفي فقط. الخطوط مضمّنة محليًا عبر Fontsource دون طلبات إلى Google Fonts. مقاسات النصوص والألوان معرفة بمتغيرات مشتركة: محتوى 16px، تسميات 14px، عناوين بطاقات 20px، وعناوين أقسام وHero متجاوبة.
- `src/components/`: الترويسة والواجهة الرئيسية ونموذج التواصل ونافذة المشروع. الأقسام الأخرى في `src/App.tsx`.

لإضافة مشروع، انسخ عنصرًا من `projects` وأعطه `id` فريدًا، واسمًا ووصفًا باللغتين وتصنيفًا وصورة. الحقول الاختيارية: `technologies`, `role`, `demo`, `repository`. لا تملأ المعلومات غير المؤكدة. تعرض الروابط الخارجية فقط إذا كانت HTTPS صحيحة دون بيانات دخول. يتولى JSX عرض البيانات تلقائيًا.

## إضافة الأصول

ضع الملفات داخل `public/` ثم استخدم مسارات تبدأ بـ`/` في البيانات؛ يحول التطبيق المسار حسب Vite BASE_URL. حُدد `base: './'` لدعم استضافة المجلد الجذري أو الفرعي.

- الصورة: أضف `profile.portrait: "/portrait.webp"`. يختفي بديل LM عند توفيرها؛ استخدم صورة مضغوطة ومناسبة للقص المربع.
- السيرة: أضف `profile.cv: "/resume.pdf"`. يظهر الزر بعد تحقق HTTP وتوقيع `%PDF-`؛ ملف مفقود أو HTML لن ينتج زرًا مكسورًا. هذا فحص مبدئي وليس تحققًا كاملًا من سلامة PDF.
- LinkedIn: أضف `profile.linkedin` برابط HTTPS معتمد، وإلا يبقى مخفيًا.
- لقطات المشاريع: استبدل ملف الصورة وحدّث `image` وغيّر `illustrative` إلى `false` فقط عند استخدام لقطة حقيقية معتمدة.

الرسومات SVG الحالية موروثة من القالب، مع إزالة الأسماء والنصوص الافتراضية؛ هي تصاميم توضيحية عامة وليست دليلًا على وظائف المشاريع أو تقنياتها.

## نموذج التواصل

يفتح `mailto:` برسالة مشفرة، وعلى الزائر إتمام الإرسال في تطبيق بريده. لا توجد خدمة إرسال أو حفظ لرسائل الزوار. يمكن نسخ الرسالة مباشرة بعد تعبئة الحقول، وعند رفض صلاحية الحافظة تظهر معاينة قابلة للنسخ اليدوي. الروابط المباشرة للبريد وواتساب متاحة دائمًا.

## الاختبارات

```sh
# اترك معاينة الإنتاج قيد التشغيل في طرفية أخرى
npm run preview
npm run test:qa
```

اختبارات Playwright تستخدم Google Chrome المثبت محليًا (`channel: 'chrome'`). يمكن ضبط `QA_URL` لاختبار عنوان محلي آخر. النتائج في `qa/results.json`، فحوص axe في `qa/axe-*.json` واللقطات في `qa/screenshots/`. تحتاج الاختبارات صلاحية الحافظة على localhost. جميع أدوات الاختبار devDependencies ولا تدخل حزمة الإنتاج.

مجلد `qa/` يُولَّد محليًا عند الاختبار ولا يُرفع إلى GitHub. تُستبعد أيضًا ملفات البناء والاعتمادات والأرشيفات وتقارير التسليم المحلية عبر `.gitignore`. يبقى سكربت الاختبار ضمن المستودع لإعادة توليد النتائج. لا تمثل اختبارات axe شهادة امتثال شاملة، ولا يغني الاختبار الآلي عن مراجعة قارئ شاشة.

## النشر

راجع `DEPLOYMENT.md`. لم يُنشر الموقع ولم يُضبط دومين أو DNS. تبقى الصورة وCV والتفاصيل المعتمدة للمشاريع والهوية الإنجليزية النهائية ضمن `CONTENT-PENDING.md`. عنوان HTML الأولي عربي؛ تحديث React للغة وmeta لا يولد صفحات HTML مستقلة لمحركات البحث التي لا تنفذ JavaScript. يمكن بحث prerender عند الحاجة لاحقًا دون تغيير الإطار الآن.
